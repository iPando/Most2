# Конфигурация списков

В этой папке находятся JSON-файлы с настраиваемыми списками. Редактируйте их напрямую в любом текстовом редакторе (Блокнот, Notepad++, VS Code и т.д.).

## Файлы для редактирования

### 1. `districts.json` — Список районов

Формат: массив строк (каждый район в кавычках, через запятую)

```json
[
  "Центральный",
  "Северный",
  "Южный"
]
```

**Как редактировать:**
- Чтобы **добавить** район — добавьте новую строку `"Название района"` перед закрывающей `]`
- Чтобы **удалить** район — удалите строку с ним (вместе с запятой на предыдущей строке, если она была последней)
- Чтобы **переименовать** — измените текст в кавычках

### 2. `departments.json` — Отделы и сотрудники

Формат: объект, где ключ — название отдела, значение — массив сотрудников

```json
{
  "Название отдела": [
    "Фамилия И.О.",
    "Фамилия И.О."
  ],
  "Другой отдел": [
    "Сотрудник 1",
    "Сотрудник 2"
  ]
}
```

**Как редактировать:**
- **Добавить отдел** — добавьте новую пару `"Название отдела": [...]` перед закрывающей `}`
- **Добавить сотрудника** — добавьте строку `"Фамилия И.О."` в массив нужного отдела
- **Удалить отдел** — удалите всю пару `"Название": [...]` (с запятой, если не последний)
- **Удалить сотрудника** — удалите строку с ним из массива
- **Переименовать** — измените текст в кавычках

### 3. `statuses.json` — Статусы обращений

Формат: массив строк

```json
[
  "Новая",
  "В работе",
  "Решена"
]
```

**Как редактировать:** аналогично `districts.json`

## Важные правила

1. **Не нарушайте синтаксис JSON:**
   - Строки всегда в двойных кавычках `"..."`
   - После каждого элемента в массиве/объекте (кроме последнего) — запятая
   - Перед закрывающими `]` и `}` запятая НЕ ставится

2. **После редактирования** пересоберите проект:
   ```
   npm run build
   ```
   Или, если вы используете приложение в режиме разработки:
   ```
   npm run dev
   ```

3. **Проверьте файл** перед сохранением — JSON не прощает ошибок (лишняя/пропущенная запятая, кавычки и т.д.)

## Примеры

### Добавить новый район
Было:
```json
[
  "Центральный",
  "Северный"
]
```
Стало:
```json
[
  "Центральный",
  "Северный",
  "Новый район"
]
```

### Добавить нового сотрудника в отдел
Было:
```json
{
  "Технический отдел": [
    "Иванов И.И.",
    "Петров П.П."
  ]
}
```
Стало:
```json
{
  "Технический отдел": [
    "Иванов И.И.",
    "Петров П.П.",
    "Сидоров С.С."
  ]
}
```

### Добавить новый отдел
Было:
```json
{
  "Отдел 1": ["Сотрудник 1"],
  "Отдел 2": ["Сотрудник 2"]
}
```
Стало:
```json
{
  "Отдел 1": ["Сотрудник 1"],
  "Отдел 2": ["Сотрудник 2"],
  "Новый отдел": ["Новый сотрудник 1", "Новый сотрудник 2"]
}
```
