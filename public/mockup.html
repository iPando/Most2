Сводный отчёт

Здесь будут выводиться отчёты по данным из обеих таблиц (СПБ и ПОС).

💡 Как это будет работать

Три вкладки в шапке позволяют переключаться между разными реестрами:

  • СПБ — текущая таблица обращений (реализована)
  • ПОС — отдельная таблица для обращений ПОС (будет аналогична СПБ)
  • Сводная — отчёты по данным из обеих таблиц

Важно: каждая вкладка будет иметь свой файл данных на сетевом диске, чтобы разные сотрудники могли работать параллельно без конфликтов.
