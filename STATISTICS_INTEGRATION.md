# Инструкция по интеграции вкладки "Статистика"

## Что было добавлено

### 1. HTML-разметка (`index.html`)
- Добавлена новая вкладка "Статистика" в панель навигации (строка 25)
- Добавлен контейнер для вкладки статистики с:
  - Заголовком и элементами управления месяцем (кнопки ← → и селектор)
  - Контейнером для таблицы статистики

### 2. JavaScript-код (`public/app.js`)
Добавлены следующие функции:

#### `initStatisticsMonthSelector()`
- Инициализирует селектор месяцев (последние 12 месяцев)
- Автоматически устанавливает текущий месяц

#### `changeStatisticsMonth(delta)`
- Переключает месяц на delta позиций (-1 или +1)
- Обновляет селектор и перерисовывает таблицу

#### `parseStatisticsData()`
- Парсит данные из `TABS.spb.complaints`
- Группирует обращения по дням месяца
- Подсчитывает метрики:
  - **Поступило** — по дате `receivedDate`
  - **Направлено ответов** — статус точно равен "Направлено ответов"
  - **Перенаправлено** — статус точно равен "Перенаправлено"
  - **Дан промежуточный ответ** — статус точно равен "Дан промежуточный ответ"
  - **Отклонено** — статус точно равен "Отклонена"
- Определяет выходные дни (суббота, воскресенье)

#### `renderStatistics()`
- Рендерит сводную таблицу в контейнер `statisticsTableContainer`
- Визуально выделяет выходные дни синим фоном (#4FC3F7)
- Пустые ячейки остаются пустыми (не отображается "0")
- Ячейки с данными выделяются светло-голубым фоном

### 3. CSS-стили (`public/styles.css`)
Добавлены стили для:
- Заголовка вкладки статистики
- Элементов управления месяцем
- Таблицы статистики (заголовки, ячейки, выходные дни)
- Легенды с пояснениями
- Адаптивного дизайна для мобильных устройств

## Структура данных

Вкладка "Статистика" работает с данными из вкладки "СПБ" (`TABS.spb.complaints`).

Каждое обращение имеет структуру:
```javascript
{
  id: number,
  complaintNumber: string,
  complaintText: string,
  district: string,
  object: string,
  receivedDate: string,        // Формат: "YYYY-MM-DD"
  responseDeadline: string,
  department: string,
  responsibles: string[],
  status: string,              // Точное совпадение для метрик
  isCompleted: boolean
}
```

## Логика подсчёта метрик

### 1. Поступило
- Считается по полю `receivedDate`
- Проверяется, что дата попадает в выбранный месяц и год

### 2-5. Остальные метрики
- Проверяется точное совпадение поля `status` (case-sensitive)
- Используется `receivedDate` как базовая дата
- **Важно**: в текущей структуре данных нет отдельного поля для даты изменения статуса

### Ограничение
Если в будущем потребуется учитывать дату фактического изменения статуса (а не дату поступления), необходимо:
1. Добавить новое поле в структуру данных (например, `statusChangeDate`)
2. Обновить функцию `parseStatisticsData()` для использования этого поля

## Как использовать

1. Откройте приложение в браузере
2. Перейдите на вкладку "Статистика"
3. Выберите нужный месяц с помощью:
   - Кнопок ← → для переключения на предыдущий/следующий месяц
   - Выпадающего списка для выбора конкретного месяца
4. Таблица автоматически перерисуется с данными за выбранный период

## Визуальное оформление

- **Выходные дни** (суббота, воскресенье) — синий фон (#4FC3F7)
- **Ячейки с данными** — светло-голубой фон (#dbeafe) с жирным шрифтом
- **Пустые ячейки** — остаются пустыми (не отображается "0")
- **Заголовок месяца** — тёмно-синий фон (#1e3a8a) с белым текстом

## Тестирование

Для проверки работы вкладки:
1. Убедитесь, что во вкладке "СПБ" есть обращения с разными статусами
2. Перейдите на вкладку "Статистика"
3. Проверьте, что таблица отображается корректно
4. Попробуйте переключить месяц кнопками ← →
5. Проверьте, что выходные дни выделены синим цветом
6. Убедитесь, что метрики подсчитываются правильно
