# Краткая инструкция по использованию

## Первый запуск

1. Откройте файл `index.html` в браузере Google Chrome или Microsoft Edge
2. При первом запуске нажмите кнопку **"📂 Открыть файл"**
3. Выберите место для файла данных на сетевом диске (например, `\\server\share\reestr_spb.json`)
4. Подтвердите доступ к файлу в диалоге браузера
5. Готово! Приложение подключено к файлу данных

## Повторный запуск

При повторном открытии `index.html` приложение автоматически подключится к ранее выбранному файлу данных.

## Создание обращения

1. Нажмите кнопку **"Новое обращение"** (синяя кнопка вверху)
2. Заполните обязательные поля:
   - Номер обращения
   - Текст жалобы
   - Район (выбор из списка)
3. При необходимости заполните остальные поля
4. Нажмите **"Добавить"**

## Завершение обращения

**Способ 1:** Кликните по чекбоксу ✓ в колонке "Завершено" в таблице

**Способ 2:** Откройте обращение на редактирование и нажмите кнопку "Завершить" внизу формы

## Поиск обращений

- Введите текст в поле поиска - будет искать по номеру, тексту, объекту, сотрудникам
- Используйте фильтр "Все статусы" для фильтрации по статусу
- Поставьте галочку "Скрыть завершённые" для скрытия завершённых обращений

## Сортировка по дате

- Кликните по заголовку столбца **"Поступление"** для сортировки обращений по дате
- Первый клик - новые обращения сверху (↓)
- Повторный клик - новые обращения снизу (↑)
- Индикатор сортировки (↓ или ↑) отображается в заголовке столбца

## Контроль сроков

- **Красный цвет** в колонке "Ответ до" - срок просрочен
- **Оранжевый/жёлтый цвет** - срок скоро истекает
- Кнопка **"Просрочено: X"** в шапке показывает количество просроченных обращений

## Настройки

Нажмите кнопку **⚙️** (шестерёнка) в правом верхнем углу для:
- Добавления/удаления районов
- Добавления/удаления отделов и сотрудников
- Добавления/удаления статусов

Все настройки сохраняются в файл данных и доступны всем пользователям.

## Экспорт/Импорт

- **Экспорт** - сохранить текущие данные в отдельный JSON-файл (для резервной копии)
- **Импорт** - загрузить данные из JSON-файла

## Переключение между реестрами

В шапке приложения есть три вкладки:
- **СПБ** - реестр обращений СПБ
- **ПОС** - реестр обращений ПОС
- **Сводная** - сводные отчёты

Каждый реестр имеет свой файл данных на сетевом диске.

## Сводный отчёт

### Просмотр отчёта
1. Переключитесь на вкладку **"Сводная"** в шапке приложения
2. Выберите нужный месяц и год в выпадающем списке "Период"
3. Отчёт автоматически сформируется на основе данных из реестров СПБ и ПОС

### Структура отчёта
- **Две таблицы**: СПБ и ПОС
- **Заголовок**: название выбранного месяца
- **Столбцы**: дни месяца с указанием дня недели
- **Выходные дни**: выделены красным фоном
- **Ячейки с данными**: синий фон, показывают количество обращений

### Показатели
**Для реестра СПБ:**
- Поступило (кликабельно)
- Направлено ответов
- Перенаправлено
- Дан промежуточный ответ
- Отклонено

**Для реестра ПОС:**
- Поступило (кликабельно)
- Направлено ответов
- Возвращено на координацию
- Переназначен исполнитель
- Отложено

### Просмотр деталей дня
1. Кликните на ячейку с данными (синий фон) в строке "Поступило"
2. Откроется модальное окно со списком всех обращений за этот день
3. В списке показаны: номер обращения, статус, текст жалобы, район, объект, ответственный, срок ответа

### Экспорт в Excel
1. Нажмите кнопку **"Экспорт в Excel"** в правом верхнем углу вкладки "Сводная"
2. Файл будет скачан в формате CSV
3. Откройте файл в Microsoft Excel - данные автоматически импортируются с правильной кодировкой

**Примечание:** CSV файл использует разделитель ";" и кодировку UTF-8 с BOM для корректного отображения кириллицы в Excel.

## Решение проблем

### Ошибка сохранения
Если появилась ошибка сохранения:
1. Убедитесь, что файл не открыт другим пользователем
2. Проверьте доступ к сетевому диску
3. Нажмите кнопку "Отключить" и подключитесь заново

### Приложение не remembers файл
Если при каждом запуске нужно заново выбирать файл:
1. Очистите кэш браузера (Ctrl+Shift+Delete)
2. Убедитесь, что используется Chrome или Edge версии 86+

### Данные не синхронизируются
Если другой пользователь не видит ваши изменения:
1. Попросите его обновить страницу (F5)
2. Убедитесь, что оба пользователя подключены к одному файлу данных
3. Проверьте, что файл успешно сохраняется (индикатор "✓ время" в шапке)

## Горячие клавиши

- **Ctrl+F** - фокус на поле поиска
- **F5** - обновить страницу
- **Ctrl+Shift+R** - полная перезагрузка (очистка кэша)
