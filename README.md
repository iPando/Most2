# Реестр обращений - Мостотрест

Веб-приложение для ведения реестра обращений граждан с поддержкой двух реестров (СПБ и ПОС).

## Структура проекта

```
dist/
├── index.html      - Главная HTML страница (9.12 kB)
├── app.js          - JavaScript логика приложения
└── styles.css      - Стили приложения
```

## Установка и запуск

### Для конечных пользователей (без установки ПО)

1. Скопируйте папку `dist/` на сетевой диск или локальный компьютер
2. Откройте файл `dist/index.html` в браузере (Google Chrome или Microsoft Edge версии 86+)
3. Приложение готово к работе!

**Важно:** Не требуется установка Node.js, npm или любого другого программного обеспечения.

### Первый запуск

При первом открытии приложения:
1. Нажмите кнопку "📂 Открыть файл" в верхней части страницы
2. Выберите место для сохранения файла данных на сетевом диске (например, `reestr_spb.json`)
3. Подтвердите доступ к файлу в диалоге браузера
4. Приложение автоматически подключится к файлу и будет сохранять все изменения

### Совместная работа

Для совместной работы нескольких пользователей:
1. Разместите `index.html`, `app.js` и `styles.css` на сетевом диске
2. Каждый пользователь открывает `index.html` в браузере
3. При первом запуске каждый пользователь выбирает общий файл данных на сетевом диске
4. Все изменения автоматически синхронизируются через общий файл

**Примечание:** Одновременно редактировать файл может только один пользователь. Если файл заблокирован, появится сообщение об ошибке сохранения.

## Функциональность

### Вкладки

- **СПБ** - Реестр обращений СПБ (полный функционал)
- **ПОС** - Реестр обращений ПОС (полный функционал, аналогичный СПБ)
- **Сводная** - Сводные отчёты (в разработке)

### Основные возможности

#### Управление обращениями
- Создание новых обращений с автоматической нумерацией
- Редактирование существующих обращений
- Удаление обращений
- Быстрое переключение статуса "Завершено" кликом по чекбоксу в таблице

#### Поля обращения
- **Номер обращения** - вводится вручную
- **Текст жалобы** - многострочное поле с возможностью раскрытия
- **Район** - выбор из списка (настраивается)
- **Объект** - вводится вручную
- **Дата поступления** - автоматически устанавливается текущая дата
- **Ответ до** - дата с подсветкой просроченных сроков
- **Отдел** - выбор из списка (настраивается)
- **Ответственные сотрудники** - множественный выбор из списка отдела
- **Статус** - выбор из списка (настраивается)
- **Завершено** - чекбокс в таблице или кнопка в форме редактирования

#### Поиск и фильтрация
- Поиск по номеру, тексту, объекту, сотрудникам
- Фильтрация по статусу
- Скрытие завершённых обращений

#### Контроль сроков
- Автоматическая подсветка просроченных сроков (красный)
- Предупреждение о скором истечении срока (оранжевый/жёлтый)
- Учёт только рабочих дней (без выходных)
- Кнопка оповещений в шапке с количеством просроченных обращений

#### Работа с файлами
- Автоматическое сохранение в JSON-файл на сетевом диске
- Экспорт данных в JSON-файл
- Импорт данных из JSON-файла
- Индикатор подключения к файлу и времени последнего сохранения

#### Настройки (кнопка ⚙️ в шапке)
- Управление списком районов
- Управление отделами и сотрудниками
- Управление списком статусов
- Все настройки сохраняются в файл данных и доступны всем пользователям

#### Дополнительные функции
- Вставка из буфера обмена для полей ручного ввода
- Раскрытие длинных текстов кликом по ячейке
- Плавающая кнопка "Новое обращение" при прокрутке
- Адаптивный дизайн для разных размеров экрана

## Формат файла данных

Файл данных имеет следующий формат JSON:

```json
{
  "complaints": [
    {
      "id": 1,
      "complaintNumber": "ОБР-2024-001",
      "complaintText": "Текст жалобы...",
      "district": "Центральный",
      "object": "ул. Ленина, д. 15",
      "receivedDate": "2024-01-15",
      "responseDeadline": "2024-01-30",
      "department": "Технический отдел",
      "responsibles": ["Иванов И.И.", "Петров П.П."],
      "status": "В работе",
      "isCompleted": false
    }
  ],
  "config": {
    "districts": ["Центральный", "Северный", ...],
    "departments": {
      "Технический отдел": ["Иванов И.И.", "Петров П.П."],
      ...
    },
    "statuses": ["Новая", "В работе", ...]
  }
}
```

## Требования к браузеру

- **Google Chrome** версии 86 или выше
- **Microsoft Edge** версии 86 или выше

Для работы с файловой системой используется File System Access API, который поддерживается только в браузерах на базе Chromium.

## Технические детали

### Архитектура
- Чистый HTML + CSS + JavaScript (без фреймворков)
- Разделение на три файла для уменьшения размера HTML
- Использование File System Access API для работы с файлами
- IndexedDB для хранения дескрипторов файлов между сессиями

### Безопасность
- Приложение работает локально в браузере
- Данные хранятся только в указанном пользователем файле
- Не требуется доступ к интернету
- Не требуется установка дополнительного ПО
- Не требуются права администратора

## Поддержка

При возникновении проблем:
1. Убедитесь, что используется поддерживаемый браузер (Chrome/Edge 86+)
2. Проверьте доступ к файлу данных на сетевом диске
3. Очистите кэш браузера (Ctrl+F5)
4. Проверьте консоль браузера (F12) на наличие ошибок
